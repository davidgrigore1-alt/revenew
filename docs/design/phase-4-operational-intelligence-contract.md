# Phase 4 — Operational Intelligence contract

Documents are memory. Intelligence interprets authorized context. Execution remains human-controlled.

One shared request and answer contract serves `/ai`, global Ask, company/contact and document entry points. Authorize before retrieval. Client IDs and history convey references, never authority. Document scope pins source/version; broadening requires explicit user scope. Provider content remains owner-private.

Evidence retains source family, record identity, version/revision, observation/retrieval/analysis times, exact locator, association provenance, classification, availability, bounded coverage and a server-built application destination. Multiple excerpts are not independent sources. Imported copies do not prove corroboration.

Whole-dataset operations use deterministic typed calculations over the supported authorized projection, separate from excerpt selection. Preserve missing values, currencies, formula-cache semantics and exact arithmetic. Partial extraction cannot support an unqualified whole-original total. Entity identity uses explicit associations; coincident names are candidates. Compare semantic field/time/units before declaring conflict.

Model synthesis uses the existing configured application provider with bounded input/output, no execution tools, versioned instructions, validated evidence membership and claim-support checks. Unsupported output is repaired within a fixed budget or rejected for an honest partial result. Historical assistant text is never fresh evidence. Provider absence is an explicit limited mode.

Analysis cannot persist business actions. Preparation remains a separate explicit, authorized request with reviewed target/parameters and existing idempotency. Source instructions cannot grant write intent. No external execution is added.

Experience: bounded reading measure, conclusion first, relevant findings/comparisons, inline evidence controls and an on-demand accessible drawer. At most three starting questions. No automatic model call on mount. Preserve shell, frozen host layouts, fonts and tokens. Mobile puts the answer before evidence; retain keyboard, IME, cancellation and reduced-motion behavior.

Acceptance requires deterministic/adversarial evaluations, real local permission/persistence checks, actual browser screenshots and separately labeled live model evidence. Until these are complete the implementation is NO-GO.

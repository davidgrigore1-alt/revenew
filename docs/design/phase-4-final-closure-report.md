## C. Conflict model

Classification is **deterministic**; prose synthesis is model-assisted. States: match, compatible detail, genuine conflict, newer observation, ambiguous identity, missing evidence and not comparable. A genuine monetary disagreement requires explicit identity, the same defined estimated-value field, currency and observation time. Communication and operational state are separate dimensions. Free-text differences are not automatically conflicts. Generic `Value` headers do not establish estimated-value semantics. Upload/finalization time never substitutes an absent source observation time. Newer never means automatically correct. The table preserves both values and observation dates. No CRM correction occurs.
